# Sample Test Images

This directory should contain sample manga/manhwa images for testing.

## Suggested Test Images

1. **Simple Page**: A manga page with 3-5 speech bubbles
   - Tests basic text detection and translation
   - Tests typesetting in various bubble shapes

2. **Cover Page**: A manga cover with title and small text
   - Tests cover mode functionality
   - Tests filtering large stylized text

3. **Dense Page**: A page with many small text regions
   - Tests performance with multiple regions
   - Tests OCR accuracy

4. **Vertical Text**: Japanese manga with vertical text
   - Tests vertical text detection
   - Tests proper text orientation

5. **Sound Effects**: Page with onomatopoeia
   - Tests SFX translation
   - Tests transliteration handling

## Adding Test Images

1. Ensure you have rights to use the images
2. Keep file sizes reasonable (<5MB)
3. Use PNG or JPG format
4. Name files descriptively (e.g., `test_simple_dialogue.png`)

## Note

Sample images are not included in this repository due to copyright concerns. 
Users must provide their own test images.
