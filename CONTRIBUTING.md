# Contributing to Manga TransJohn

Thank you for your interest in contributing to Manga TransJohn!

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/AmazingFeature`)
3. **Commit your changes** (`git commit -m 'Add some AmazingFeature'`)
4. **Push to the branch** (`git push origin feature/AmazingFeature`)
5. **Open a Pull Request**

## Development Setup

See the README for setup instructions.

## Code Style

### Backend (Python)
- Follow PEP 8
- Use type hints where appropriate
- Add docstrings to functions
- Keep functions focused and single-purpose

### Frontend (TypeScript)
- Use TypeScript strict mode
- Follow React best practices
- Use functional components with hooks
- Keep components small and reusable

## Testing

Before submitting a PR:
1. Test the full pipeline with at least one manga image
2. Verify all API endpoints work
3. Check that the UI is responsive
4. Test error handling

## Feature Ideas

- Better inpainting (LaMa implementation)
- Batch processing UI
- Advanced region editing tools
- Custom font selection
- Translation history
- Multiple translation engines

## Bug Reports

When reporting bugs, please include:
- Operating system
- Docker version (if using Docker)
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

## Questions?

Open an issue with your question!
